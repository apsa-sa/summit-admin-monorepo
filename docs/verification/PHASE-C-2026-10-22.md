## Root cause and implemented scope

Three shared packages had manifests but no buildable/exported implementation.
They now produce ESM/declarations with the existing TypeScript compiler. Tokens
and UI export generated/copied CSS with package-owned CSS type declarations,
so a strict Next.js consumer needs no ambient CSS workaround. Turborepo orders
actual dependencies; shared build/config files participate in cache invalidation.
Only generated owned `dist` directories are reset, with path/symlink guards.

Owner palettes, semantic states, typography/spacing/radii/shadows/motion, logical
properties, reduced motion and forced colors are centralized. Noto Sans Arabic
400/600 and all referenced subsets are self-hosted with upstream OFL notice.
All component exports (including the Dialog/Modal alias) are React classes. Text,
state and callbacks come from consumers; no business/storage/auth logic is in UI.
Localization provides Arabic/English labels, direction and validated formatting.

The existing bounded proof consumes built package names, styles and types in a
real interactive gallery. Original proof routes, entry functions, session flow
and DOM admin are retained. This does not replace the final Next admin product.
No new functional entry, hook or architecture exception. ADR-0002 records build
alternatives/dependency review and acceptance requirements, not a waiver.
